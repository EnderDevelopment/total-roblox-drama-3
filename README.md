# Total Roblox Drama

Total Roblox Drama is a Roblox script designed to enhance the gaming experience by providing a dynamic and engaging environment. This script includes server-side logic to handle player interactions and a client-side UI to display a welcome message, making it an ideal choice for developers looking to add interactive elements to their Roblox games.

## Install

1. **Download the script**: Clone or download the repository from GitHub.
2. **Place the scripts**:
   - Place `TotalRobloxDrama.server.lua` in the `ServerScriptService` of your Roblox game.
   - Place `TotalRobloxDramaUI.client.lua` in the `StarterPlayerScripts` of your Roblox game.

## Use

1. **Run the game**: Start your Roblox game.
2. **Experience the UI**: Players will see a welcome message displayed on their screen.
3. **Interact with the game**: The server-side script will log player joining and leaving events.
